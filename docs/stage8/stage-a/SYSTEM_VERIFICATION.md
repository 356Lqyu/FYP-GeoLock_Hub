## Common evidence and completion contract

For every row retain test ID, role/pseudonymous subject, exact input/request UUID, original response or typed transport uncertainty, UTC DB timestamps, monotonic request elapsed milliseconds, source/migration/configuration/app hashes, before/after scoped business rows and audit IDs. Capture UI screenshots from the tested build. Store private identifiers locally; exclude passwords, JWTs, service/worker keys, raw DSNs, donor names/addresses/photos/exact coordinates and arbitrary error details from published material.

An operation passes only when its committed state, response, UI and authorization agree. A transport error never proves rollback. Preserve the request and inspect authority before a retry. Rejection leaves business state unchanged; security failures must not disclose foreign records. Required audit failures roll back the protected operation; events lost to rollback require the explicitly designed durable failure channel. The current durable failure ledger applies to claim_listing, not every RPC.

The nine persisted donation states remain SUBMITTED, AVAILABLE, HUB_ASSIGNED, AT_HUB, BATCHED, CLAIMED, PICKUP_IN_PROGRESS, COLLECTED, CANCELLED. CLOSED is a listing state. Lease is 360 minutes, database-time based, renewal disabled. Physical expiry does not authorize automatic release when custody is uncertain.

Sources: Flutter `auth/auth_controller.dart`, `main.dart`, `dashboard_pages.dart`, `donation_pages.dart`, `routing/ngo_routing_repository.dart`, `routing/ngo_routes_page.dart`; current 20261022/23/24/27/28/31 migrations; new Stage A forward review files. All code paths are under `frontend/geolock_hub_app/lib` unless specified.
