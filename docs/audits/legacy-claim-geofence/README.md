# Legacy claim and geofence experiment evidence

This bundle preserves historical integration-test scripts and CSV outputs from the former `experiments/atomic_claim/` and `experiments/geofence/` directories. These artifacts are not part of the final GEOLOCK-BM-v3.3 E2/E4 benchmarks.

The scripts are retained for historical reference only. Executing them may require their original environment, dependencies, paths, and database configuration; review them before any use. The former `.env` files were not included. No credentials are included in this evidence bundle.

Paths below `atomic_claim/` and `geofence/` preserve the relative layout from `experiments/`. `SHA256SUMS.json` records each relocated file hash. Existing historical source-hash records retain their original path names and provenance.
